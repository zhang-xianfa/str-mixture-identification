# 法医物证多人身份鉴定 —— STR 混合图谱解析

「深圳杯」数学建模竞赛 D 题「法医物证多人身份鉴定问题」的建模与求解代码。

## 一、问题背景

短串联重复序列（STR）因其高度多态性，是 DNA 身份鉴定的核心标记。通过荧光标记毛细管
电泳检测，可得到包含等位基因片段长度、峰高 / 峰面积信息的电泳图谱。

在多人作案的现场，生物检材常为**多个个体的混合样本**，其 STR 图谱表现为多套等位基因
的叠加，带来四重挑战：

1. **贡献者人数未知** —— 低比例贡献者的信号可能被高丰度信号掩盖或被检测阈值截断；
2. **混合比例未知** —— 主 / 次贡献者的相对含量直接影响后续基因型推断的可靠性；
3. **基因型组合多解** —— 同一组峰可能由多个体的不同等位基因组合叠加而成；
4. **背景噪声干扰** —— 仪器误差与环境干扰引入基线漂移和随机噪声峰。

本仓库针对这四个问题，分别给出分类模型、贝叶斯推断模型、深度回归模型与信号去噪流程。

## 二、方法总览

| 问题 | 任务 | 方法 | 结果 |
|---|---|---|---|
| 问题一 | 判断混合样本的贡献者人数（2~5 人） | XGBoost + 五折分层交叉验证 | 测试集准确率 **88%** |
| 问题二 | 解析各贡献者的 DNA 混合比例 | 贝叶斯神经网络（Pyro），狄利克雷先验 | 测试集 **MAE 0.0671** |
| 问题三 | 从混合图谱推断每个贡献者的基因型 | 分层一维卷积神经网络 | 2/3/4/5 人混合准确率 **57% / 55% / 51% / 35%** |
| 问题四 | 抑制图谱噪声、还原真实等位基因峰 | Savitzky-Golay 自适应滤波 + 峰检测 | 输出去噪谱图与峰表 |

## 三、各问题实现

### 问题一：贡献者人数判断 —— `src/q1_contributor_count_xgboost.py`

以「每 16 个等位基因构成一个完整 STR 混合图谱」为单位，从附件 1 中提取 51 组样本。

- **数据预处理**：等位基因编码归一化，`X` → 99、`Y` → 100，其余保留数值；
  对缺失值按类型填充（数值列填 0）。
- **特征工程**：从峰数量、峰高分布、基因座维度抽取多维特征。
- **类别不平衡**：自实现 `manual_oversample`，对少数类样本做有放回重采样，
  避免模型偏向多数类（2 人混合样本数远多于 5 人）。
- **模型**：XGBoost 多分类 + `StratifiedKFold` 五折交叉验证，
  以 `cross_val_predict` 汇总各折预测后输出分类报告。

### 问题二：混合比例解析 —— `src/q2_mixture_ratio_bnn.py`

把混合比例预测建模为**概率推断**问题，而非点估计。

- **特征构造**：`build_features(df, max_alleles=14, feature_length=60)` 计算不同基因座间
  的等位基因强度差异、峰高变异系数等指标，拼成定长特征向量。
- **标签解析**：`extract_ratio_with_padding` 从形如 `1:2:3` 的比例字符串中解析各贡献者
  占比，并**按最大人数补齐**，使不同人数的样本共用同一套标签格式。
- **模型**：`DynamicBayesianNN(PyroModule)` —— 贝叶斯神经网络的输出层大小
  **随贡献者人数动态调整**，并对权重设置 `PyroSample` 先验；
  混合比例的先验取**狄利克雷分布**（单纯形上的自然先验，与「占比之和为 1」的约束天然吻合）。
- **训练**：自定义 `DNADataset` 与 `collate_fn`，使同一 batch 内人数不同的样本能够共存。

### 问题三：基因型推断 —— `src/q3_genotype_cnn.py` / `src/q3_genotype_cnn_v2.py`

把 STR 图谱表示为 **16（基因座）× 500（片段长度）** 的标准化矩阵作为输入，
输出为各贡献者的基因型向量。

- `q3_genotype_cnn.py`：`STRGenotypeCNN`，输出 64 维 —— 16 基因座 × 2 个等位基因
  × 2 名贡献者，面向两人混合。
- `q3_genotype_cnn_v2.py`：`STRGenotypeCNN3Contrib`，输出 96 维 ——
  16 × 2 × 3，面向三人混合；并额外提供 `predict_3contrib()` 作为独立推理入口，
  可直接加载权重对新样本预测。
- 训练采用复合损失（多标签分类损失 + 辅助项）以提升拟合效果。

### 问题四：图谱去噪 —— `src/q4_peak_denoising.py`

三级去噪流程：

1. **去基线漂移**：Savitzky-Golay 自适应滤波（`scipy.signal.savgol_filter`）
   消除环境干扰与仪器偏差导致的低频基线漂移，恢复真实基线；
2. **抑制高频噪声**：优化滑动窗口长度与多项式阶数后做二次卷积滤波，
   抹掉高频随机噪声同时保留等位基因信号特征；
3. **剔除阴影峰**：基于 `find_peaks` 的峰检测结果，移除间距过近的伪峰，
   避免把重叠信号的肩峰误判为独立等位基因。

`main_denoising_workflow()` 逐样本处理并输出可视化对比图与峰表到 `results/`。

## 五、运行

```bash
pip install -r requirements.txt

python src/q1_contributor_count_xgboost.py     # 贡献者人数分类
python src/q2_mixture_ratio_bnn.py             # 混合比例贝叶斯推断
python src/q3_genotype_cnn.py                  # 基因型推断（两人混合）
python src/q3_genotype_cnn_v2.py               # 基因型推断（三人混合）
python src/q4_peak_denoising.py                # 图谱去噪与峰检测
```

> 问题二、三依赖 PyTorch，建议在支持 CUDA 的环境下运行；
> 代码会自动回退到 CPU（`torch.cuda.is_available()`）。

## 六、实验过程代码

`src/` 下是最终提交的四个问题求解脚本。但从拿到附件到定下方法，中间先做了一轮
数据探索与特征尝试，这些保留在 `experiments/`（**8 个脚本，约 2000 行**）：

| 目录 | 做什么 |
| --- | --- |
| `lab1/` | 附件数据的解析与可视化探索 —— 逐样本提取峰位与峰高分布，比较不同人数 / 不同混合比例下图谱形态的差异。`lab_4.py`（476 行）里实现了按**报告阈值过滤低峰**，并单独处理 AMEL 基因座的特殊性 |
| `test0/附件一.py` | 针对附件 1（不同人数）的专门分析（358 行） |
| `test2/` | 早期直接用 **XGBoost 做分型**的尝试（`Q1.py` / `lob_1.py`），以及一份独立的数据预处理脚本 |

> 这几份是探索期的代码，命名与结构保留了实验时的原样，跟 `src/` 下的最终版本相比
> 更零散、也有重复。保留它们是为了完整呈现从「先把数据看明白」到「定下模型」的过程 ——
> 比如正是因为先发现了「低峰容易被误判成等位基因」，才有了问题四那套去噪流程。
